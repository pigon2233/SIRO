# os/backup/ - 備份 / 還原

> Phase 6 實作。SIRO 故障時能在 10 分鐘內還原。

## 備份策略

### 什麼要備份

| 對象 | 重要性 | 頻率 |
|------|--------|------|
| 使用者對話歷史 | 高 | 即時（每次對話後） |
| 個人化設定（personality） | 中 | 每天 |
| 系統 log | 低 | 每天 |
| 系統設定（/etc/siro） | 中 | 改動時 |
| 系統 image | 高 | 每月 + 改動時 |

### 備份目標

- **本地**：另一個分割區（防止同碟故障）
- **遠端**：可選，自己的 NAS 或雲端
- **不加密也行**（內容不是祕密），但建議加密傳輸

### 備份工具

- `rsnapshot` 或 `borgbackup` 做差異備份
- `restic` 做版本化備份（推薦）
- `cron` 排程

## 還原策略

- **從備份還原**：restic restore
- **從 image 還原**：USB 重灌 + 套用備份
- **從零還原**：Packer 重建 image + 套用備份

## 災難演練

- 硬碟故障：備份能還原嗎？
- 設定檔損壞：能 rollback 嗎？
- 整台不開機：能從 USB 救嗎？

每季演練一次。

## 不在 Phase 6 範圍

- 自動 failover（多機叢集）
- 雲端原生備份（K8s 之類）
- 區塊層級備份（DRBD 之類，太複雜）
