# os/video/ - 視訊（攝影機）設定

> Phase 5 實作。給 Live2D 角色「看」的能力。

## 用途

- 人臉追蹤（v1+）
- 表情判斷（v2+）
- 手勢辨識（v3+）
- 安全偵測（陌生人 / 入侵者，v3+）

v0 不用攝影機，這是 Phase 5 才開始。

## 硬體選擇

| 類型 | 優點 | 缺點 |
|------|------|------|
| 內建視訊 | 整合、免設定 | 角度受限 |
| USB 視訊 | 可調整位置 | 要藏線 |
| 廣角魚眼 | 範圍大 | 邊緣失真 |
| 深度攝影機（RealSense） | 3D 資訊 | 貴、Linux 驅動麻煩 |

Phase 5 先用內建，之後看需求升級。

## 軟體堆疊

```
應用層: siro-runtime (Rust) 或 bridge (Python)
        ↓ v4l2
系統層: Linux kernel driver
        ↓
硬體:   UVC / 特定相機
```

## 隱私

- 攝影機燈號永遠開（如果硬體支援）
- 影像只在本地處理，不上傳
- 偵測到的特徵（臉、表情）不存 log
- 可以用實體開關關閉攝影機

## 不在 Phase 5 範圍

- 多攝影機（v3+）
- 視訊串流到外部（永遠不做）
- 深度感知（v3+）
